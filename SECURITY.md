# Security policy

## Supported versions

| Version | Security support |
| --- | --- |
| `0.3.0` | Best-effort fixes for the parked keeper release |
| `0.3.0-alpha.1` | Superseded public prerelease |
| Earlier pre-public versions | Not supported from this repository |

Pre-1.0 support may include breaking changes and does not promise a fixed response or maintenance period.

## Reporting a vulnerability

Do not disclose a suspected vulnerability, credential, exploit detail, or affected user information in an ordinary GitHub issue, discussion, pull request, or public channel.

GitHub private vulnerability reporting is active. Use the repository’s **Security → Report a vulnerability** flow. There is no public security email; do not put sensitive details in an ordinary issue.

The maintainer will acknowledge, triage, reproduce, coordinate remediation, and decide disclosure timing. Reports should include affected version, impact, prerequisites, minimal reproduction, and any suggested mitigation, while avoiding unnecessary personal data or live credentials.
