# Governance

DevPulse is currently a single-maintainer project. `@Abdulrehman-glitch` is the maintainer and final decision-maker for scope, architecture, merges, releases, licensing, security response, and repository administration.

## Triage and review

New public issues begin in `status: needs-triage`. The maintainer confirms scope, priority, area, acceptance criteria, dependencies, and milestone before marking work ready. Pull requests are evaluated for correctness, focused scope, tests, security and privacy impact, dependency compliance, documentation, and maintainability.

No committee, team, or second approver is implied. The maintainer may seek specialist review, but retains release and security authority. Security information is handled privately until coordinated disclosure is safe.

## Decisions and conflict resolution

Routine decisions are recorded in issues and pull requests. Material architectural, compatibility, governance, or release decisions should be documented in repository documentation or a future decision record. The maintainer resolves disagreements by considering user safety, evidence, project scope, long-term maintenance cost, and the published licence and security boundaries.

## Releases

Only the maintainer approves a release. Release approval requires the documented validation, dependency, security, provenance, signing-status, changelog, and rollback gates. Emergency changes may use a documented maintainer bypass where a ruleset permits it, followed by prompt retrospective evidence; bypass is not a substitute for ordinary review.

## Future maintainers and continuity

Additional maintainers may be added after sustained, trustworthy contributions and demonstrated judgment in review, security, and release work. Their authority and repository access must be documented before it is exercised.

If the current maintainer cannot continue, the project may enter maintenance-only mode, transfer to a documented successor, or be archived. No successor, organization, or committee is currently promised.
