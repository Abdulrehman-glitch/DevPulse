# Asset provenance

## Interim DevPulse mark

The retained application icons are generated from `assets/branding/devpulse-mark.svg` by `scripts/generate-brand-assets.mjs` and the locked Tauri CLI. The source uses only an original rounded rectangle and pulse-shaped geometric path, with no font or third-party imagery. It was created for this curated staging repository and is distributed under Apache-2.0 as project material.

This is an interim project-owned identity pending future brand design. It does not imitate or incorporate another project’s branding. The generator and exact output hashes are recorded in the private staging audit and its machine-readable asset inventory.

Redistribution and modification are permitted under Apache-2.0. Confidence is high because the construction source and generation procedure are committed.

## Excluded media

The pre-public overview image was excluded because its embedded provenance did not support the historical description of the image. No product screenshot is included in this curated history. The original icon family was also excluded because its ownership and redistribution evidence was incomplete.

No retained font, animation, sound, executable, bundled binary, or other generated media file is committed. Runtime and installer artifacts are generated only into ignored or private audit output paths.
