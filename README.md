# DevPulse

DevPulse is a Windows desktop application for viewing local development-project and system-health information through a Tauri interface and a loopback-only Python service.

This repository is an initially private publication-staging candidate. Its Git history starts from a curated pre-public baseline; it does not reproduce the private development history or historical release provenance. See [PUBLICATION_STATUS.md](PUBLICATION_STATUS.md).

The project is not accepting contributions during staging. Licensing, security remediation, dependency compliance, governance, and validation are completed in later staging commits before any public launch decision.
