# Publication status

This is the public DevPulse repository. Its history was curated from a separately preserved private pre-public codebase.

Public history begins with the curated baseline. Historical development and versions through `v0.2.0-beta.1` remain preserved privately; this repository does not recreate their release provenance.

The first public release was `0.3.0-alpha.1`. The `0.3.0` keeper release remains pre-1.0 and is not a production or long-term support commitment. Apache-2.0 licensing, dependency compliance, asset provenance, authenticated local-token handoff, public CI, private vulnerability reporting, and repository governance apply to this history.

An installer may be attached to a release only after the exact commit passes the manual-only `Release QA` workflow on a standard disposable Windows runner. The release tag is created after that gate; earlier private tags are never recreated or moved here.
