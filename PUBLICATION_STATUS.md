# Publication status

This repository is an initially private, curated staging candidate derived from a preserved private pre-public DevPulse codebase.

Public history begins with this curated baseline. Historical development and versions through `v0.2.0-beta.1` remain preserved in a private archive; this repository does not recreate their release provenance. No public release has been issued from this history.

The codebase is prepared as `0.3.0-alpha.1`; no tag or release has been created. Apache-2.0 licensing, dependency compliance, asset provenance, local-token remediation, and repository governance have been completed locally. Full build/security validation and private GitHub staging verification must pass before the Phase 1D human go/no-go review.

Contributions are not accepted during staging. Public visibility, public CI, launch rulesets, vulnerability-reporting activation, installer lifecycle validation, and prerelease publication remain Phase 1D gates.
