# Support

DevPulse is an alpha-stage project without a service-level agreement or private support contract.

During private staging, support requests are limited to authorized staging participants using the repository’s existing private issue channel. After public launch, use the most specific issue form for reproducible bugs, performance problems, documentation gaps, or feature proposals. Search existing issues first and include environment, version, steps, expected behavior, actual behavior, and non-sensitive diagnostics.

Do not use support channels for vulnerability disclosure; follow [SECURITY.md](SECURITY.md). Do not include access tokens, private repository content, personal paths, or diagnostic archives without reviewing and redacting them.
